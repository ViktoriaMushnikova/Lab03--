1. Разницы в результате нет. x += 5 - это просто сокращённая запись для x = x + 5.
2. x++ сначала передаёт старое значение в Console.WriteLine, а потом увеличивает переменную. ++x сначала увеличивает переменную, и только потом передаёт новое значение в вывод.
3. Всегда получается тип bool.
4. Это когда программа прекращает вычисление логического выражения, если ответ уже очевиден. Для && если первая часть false, вторая часть даже не проверяется. Для || если первая часть true, вторая часть даже не проверяется. Пример = bool result = (b != 0) && (a / b > 2) - если b равен 0, то первая часть выдаст false и программа не станет делать деление во второй части, благодаря чему не произойдёт вылет деления на 0. 
5. Приоритет сначала умножение и деление(слева направо), потом сложение и вычитание(тоже слева направо).
1) 2 * 3 = 6
2) 4 . 2 = 2
3) 10 - 6 = 4
4) 4 + 2 = 6
Ответ: 6
6. Чтобы легче было читать и людям не приходилось вспоминать приоритет операторов. Это уменьшает шанс сделать глупую ошибку.
